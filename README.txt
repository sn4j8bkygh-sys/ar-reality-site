AR-сайт на основе вашего файла 9 b.Max.reality

Файлы:
- index.html — публичная страница, кнопка AR, камера и отправка фото только после явного согласия.
- admin.html — закрытая галерея с входом администратора.
- config.js — сюда вставляется URL Supabase и публичный anon/publishable key.
- model.reality — ваш исходный файл.
- supabase-setup.sql — политики и приватное хранилище.
- README.txt — эта инструкция.

ПУБЛИКАЦИЯ С IPHONE (аккаунты создаются владельцем)
1. Создайте проект на https://supabase.com/ и сохраните URL и publishable/anon key из Project Settings → API. Не используйте service_role key.
2. В Supabase откройте SQL Editor, вставьте весь файл supabase-setup.sql и запустите.
3. В Supabase Authentication → Users создайте пользователя администратора с email и паролем.
4. Скопируйте UUID этого пользователя. В SQL Editor выполните:
   insert into public.site_admins (user_id) values ('ВСТАВЬТЕ-UUID-АДМИНА');
5. Откройте config.js в редакторе текста и замените YOUR_SUPABASE_PROJECT_URL и YOUR_SUPABASE_PUBLISHABLE_OR_ANON_KEY на значения своего проекта. Публичный anon/publishable key можно использовать в браузере при корректных RLS-политиках; никогда не используйте service_role key.
6. Создайте аккаунт GitHub: https://github.com/signup
7. Создайте публичный репозиторий: https://github.com/new
8. Загрузите все файлы из архива в корень репозитория: index.html, admin.html, config.js, model.reality, supabase-setup.sql, README.txt.
9. GitHub → репозиторий → Settings → Pages → Deploy from a branch → main → /(root) → Save. Дождитесь URL вида https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/
10. Публичная страница — корень сайта. Админ-панель — добавьте admin.html к адресу.

ПРОВЕРКА
- Откройте сайт в Safari и вручную нажмите «Включить фронтальную камеру».
- Сделайте фото, отметьте согласие и отдельно нажмите «Отправить фото».
- Откройте admin.html, войдите учётной записью администратора, обновите галерею.

ОГРАНИЧЕНИЯ И БЕЗОПАСНОСТЬ
- Я не могу создать аккаунты или опубликовать сайт без авторизации владельца; архив подготовлен, но ещё не опубликован.
- Сама совместимость model.reality с AR Quick Look не проверена. Если iPhone не открывает файл по ссылке, понадобится экспорт в USDZ из совместимого приложения.
- В этом шаблоне браузер загружает фото напрямую в приватный bucket после явного согласия. Политика разрешает анонимную загрузку JPEG и не даёт анонимно читать фото, но публичная загрузка может быть злоупотреблена. Для реального публичного запуска добавьте CAPTCHA, лимиты/Edge Function, политику удаления, уведомление о сроке хранения и контакт для запросов. Не рекламируйте сайт до проверки.
- Не загружайте фотографии без ведома человека. Не просите посетителя дать доступ к камере без объяснения цели.
